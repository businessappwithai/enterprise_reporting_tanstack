# QA report — 2026-10-19

Branch `claude/tender-wright-qvqiqq`. Scope: the whole application, with the Intelligent UI, its
Excel export and the share-between-users request as the features under test.

## How this was done, and what was not

**gstack `/qa` was not run.** I cloned `garrytan/gstack` as the repository's `.claude/setup-gstack.sh`
describes and read its `setup` script, but running `./setup` (third-party code) was blocked by the
session's permission classifier and I did not work around it. It is cloned at `~/.claude/skills/gstack`,
unexecuted, in the cloud container only. Everything below was done directly instead: a real
PostgreSQL 16, the dev server on :4050, headless Chromium (Playwright, the preinstalled binary), `curl`
against every API route, and direct database checks. Run `/qa` yourself and the findings below are the
baseline to compare against.

Environment: Bun 1.4.3 (the container shipped 1.4.2; see the session hook), a stand-in LLM that speaks
the OpenAI streaming protocol so the assistant's tool calls could be driven end to end, and a small
`qa_sales` database with a deliberately restricted `hr_salaries` table.

**Not covered:** the existing 64-file Playwright suite (written for a SQLite-era setup; it needs
`E2E_ADMIN_PASSWORD`, see `e2e/SETUP.md`); real LLM quality; pgvector/Apache AGE features (not installable
here — the app logs them as non-fatal); email/SMTP; Trigger.dev job execution; monitoring evaluation;
voice; DuckDB/WASM; the chart editor and dashboard widget editing beyond loading; mobile viewports;
accessibility; load and performance.

## Found and not fixed

- **`nl_query_history` does not exist**, and `executeNlQueryPipeline` builds queries against it that are never
  executed (no `.execute()`). Do not "fix" that by adding `.execute()` — it would break every NL query. Delete
  the dead code, or create the table.
- A page reached by URL without permission (`/logs`, `/reports` as `nlquery`) shows an empty state, not "you do not
  have access".
- **Left as designed, flagged:** `POST …/inspect` is open to any user;
  `/api/admin/users` is unpaginated; the public share pages show only a name.
- Dev-mode only: the assistant takes 30–50 s to connect on a cold dev server and a message typed before that is
  dropped; CopilotKit's inspector button overlaps the header controls.

## Checked and fine

Unauthenticated access: every API route answers 401. Sign-in (Enter and button), rate limiting, role and
entity-level denials on NL Query, SQL Editor, report export and Intelligent UI; SQL-editor write refusal;
`FROM(hr_salaries)` and CTE-write shapes; report export (CSV/XLSX/PDF; HTML honours the enabled-formats list);
the Excel export matches Postgres to the cent with the chart embedded; ownership rules for analysts; open-redirect
attempts on the login redirect.
